## MODIFICADORES Y ESTADOS

### Estados de Hover
- Todos los elementos interactivos tienen estados :hover definidos
- Transformaciones translateY(-2px a -4px)
- Cambios de color y sombras

### Estados de Focus
- Inputs tienen outline con color primario
- Box-shadow con opacidad 10%
- Inputs con error tienen box-shadow rojo

### Estados Disabled
- Opacidad 50%
- Cursor not-allowed
- Sin transformaciones

### Animaciones
- fadeIn                      → Fade in suave
- slideDown                   → Deslizar hacia abajo
- slideUp                     → Deslizar hacia arriba

---

## RESPONSIVE BREAKPOINTS

### Desktop (>1024px)
- Layout completo con sidebar expandido
- Todos los elementos visibles

### Tablet (768px - 1024px)
- Sidebar colapsado por defecto
- Quick actions sin labels
- Placeholder cards en columna única

### Mobile (480px - 768px)
- Sidebar overlay
- Navbar simplificado
- User info oculto
- Search oculto
- Elementos compactos

### Mobile Small (<480px)
- Elementos aún más compactos
- Botones full width
- Dropdowns fixed bottom
- Padding reducido

## NOTAS DE USO

1. Todos los componentes usan variables SCSS
2. Transiciones suaves (150-300ms)
3. Sombras sutiles para profundidad
4. Border radius consistente
5. Espaciado basado en múltiplos de 4px
6. Colores semánticos para estados
7. Responsive mobile-first
8. Animaciones con ease-in-out
9. Z-index organizados por capas
10. Opacidades estandarizadas (10-100%)
11. Inputs con estados focus, error y disabled
12. Tables con hover en filas y scroll horizontal
13. Select con flecha SVG personalizada
14. Formularios con grid responsive
